# Play log template

A **play log** (Johno's word, 2026-10-19) sits next to anything we make: a construct, a TD packet, a sketch, a Blender model, an AE comp, a cue sheet, a draft. File name: **`play-log-<thing>.md`**, named after the thing (`play-log-rimrock-trivia-xp.md`, `play-log-pine-trees-cv.md`), so several can sit in one folder and still be told apart. No date in the name: it is one file that grows, with a dated heading per session inside.

Where it goes: **in a project or sketch, its `resources/`** (`rimrock-trivia-xp/resources/play-log-rimrock-trivia-xp.md`); a construct keeps it in its own folder (`constructs-JB/pine-trees-cv/play-log-pine-trees-cv.md`). Changed 2026-10-19 from `play-log.md` in the thing's folder, which put it in a sketch's root and left several play logs in one place with the same name.

It keeps every try on *this one thing*, kept or dropped, with the why. The thing itself only keeps what survived; the play log keeps the road there, so dead ends aren't tried twice and the reasons stay.

- **Not a session log:** a session log tells one session's story across a project. A play log stays with one thing, across every session.
- **Not gotchas:** gotchas hold for every thing of that kind ("TD pauses on space"). A play log line that turns out to hold everywhere gets promoted to the skill's gotchas or rules.

Rules:
- One line per try: **what we tried → kept / dropped / changed / fixed → why**, plain words.
- Newest session on top, under a heading: date · where (versions, `.toe`, project).
- Johno's own words in quotes when he gave the reason.
- Close each session's block with **the pick** (where it's saved) and **how the play went** (one line).
- The companion working on the thing reads it before the first change, and adds lines as tries happen or before the session ends. SLC checks it at sl time (Workflow 4, Step 5b).

---

```markdown
# Play log · <thing name>

One line per try: what we tried → kept / dropped → why. Read this first at the start of a session on this <thing>, so dead ends aren't tried again. Newest session on top.

## YYYY-MM-DD · <versions or file> (<project>)

Started from: <where this session began, one line>.

- **<what we tried>** → kept. <why, in a few words>.
- **<what we tried>** → dropped. <why>.
- **<what we tried>** → changed: <to what>. <why>.
- **<what broke>** → fixed: <how>. <the lesson>.

**Johno's pick:** <where it's saved>.

**How the play went:** <one line: what made it fast or slow>.
```

Examples: `idocs26_for_work/resources/constructs-JB/pine-trees-cv/play-log-pine-trees-cv.md` (the first one), `rimrock-trivia-xp/resources/play-log-rimrock-trivia-xp.md` (a sketch).
