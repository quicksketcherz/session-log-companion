# Knowledge Log Template

**One shape for every knowledge log** (agreed 2026-10-18; replaces the discovery and learning templates). A discovery (it broke, here's the fix) and a learning (how a thing works) use the same headings. "Test your understanding" is the one optional block, for when Johno is learning a tool.

**Where it goes:** Workflow 2 in `SKILL.md`. One new file per session, never added to an old log.

**File name:** `YYYY-MM-DD-HHMM-Brief-Title.md`, the stamp shared with the session log. With screenshots, a folder of the same name with the `.md` and `attachments/` inside.

---

```markdown
# [What this log is about, in plain words]

**Date:** YYYY-MM-DD · HHMM
**Shelf:** tools/<tool> or interests/<interest> · [app + version when it's a tool]
**Session log:** `<path to the session log this came from>`
**Related:** `<older log on the same topic>` · `<another>` (from the shelf's README; leave out when none)

---

## The Gap

**Trying to do:** [the goal]
**What we expected / what the AI said:** [the first idea]
**Where it broke, or what wasn't clear:** [the error, or the question]
**What works:** [the fix, or the answer, in one or two lines]

---

## Working Example

[The setup, code or steps that work, with where each piece lives and what it does]

**Key settings:**
- `name`: `value` — why it matters

**You should see:** [the result]

---

## Why This Matters

**Why it's easy to get wrong:** [old docs, a version change, a guess that sounds right]
**What it shows about the tool:** [the principle]

---

## Commands Used

- `[command]` — what it did

---

## Questions to Explore Next

1. [an experiment or variation]
2. [a related case]

---

## Test Your Understanding  *(optional — when learning a tool)*

1. [the core idea, in your own words]
2. [when would you use this over the other way?]

---

## Links

- [docs, references, the version tested]
```

---

**Client names** are allowed (it's Johno's order-pack reference). When the log names a client, say so in one line as you write it: "this log names Lilly and the Foundayo book".
